# Mohit Sharma — Portfolio

Personal portfolio website showcasing my work in backend, full-stack, and AI-integrated software engineering.

**Live site:** _coming soon_

## Tech Stack

- **React 19** + **Vite** for a fast, modern dev experience
- **Tailwind CSS** for styling
- **JavaScript (JSX)**

## Sections

- Hero with quick links and resume download
- About Me
- Education
- Technical Skills
- Featured Projects (Inventory App, AutoQA, Model Fine-Tuning Platform, RAG Playground)
- Other Selected Work
- Contact

## Getting Started

Clone and install dependencies:

```bash
git clone https://github.com/mohit716/mohit-sharma-portfolio.git
cd mohit-sharma-portfolio
npm install
```

Run the dev server:

```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

## Build for Production

```bash
npm run build
npm run preview
```

The production-ready files will be in the `dist/` folder.
